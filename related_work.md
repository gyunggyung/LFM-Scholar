# Related Work

## Theme 1: **Efficient Sequence Modeling**
- [liu2024vmamba] *VMamba: Efficient Visual Representation Learning with Bidirectional State Space Model*
  Abstract: VMamba adapts Mamba, a state-space language model, into a vision backbone with linear time complexity. At the core is a stack of Visual State-Space (VSS) blocks with efficient memory usage and computation.
- [zhu2024vision] *Vision Mamba: Efficient Vision Transformer using Bidirectional State Space Model*
  Abstract: Vision Mamba replaces parts of Vision Transformers with bidirectional state-space models to improve efficiency while maintaining performance.
- [he2024panmamba] *Pan-Mamba: Effective Pan-Sharpening with State Space Model*
  Abstract: Pan-Mamba uses a state-space model for pan-sharpening, demonstrating efficient and effective image fusion.
- [shams2024ssamba] *SSAMBA: Self-Supervised Audio Representation Learning With Mamba State Space Model*
  Abstract: SSAMBA applies Mamba to self-supervised audio representation learning, achieving competitive performance with Transformers.

## Theme 2: **Efficient Neural Architectures**
- [loh2024comparative] *A Comparative Evaluation of Transformers in Seq2Seq Code Mutation*
  Abstract: Evaluates the efficacy of Transformers in code mutation testing, highlighting the impact of trivial mutants.
- [bojanowski2017enriching] *Enriching Word Vectors with Subword Information*
  Abstract: Proposes a method to enrich word vectors using subword information, improving performance on low-resource languages.
- [raffel2019exploring] *Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*
  Abstract: Investigates transfer learning using a unified text-to-text transformer framework.

## Theme 3: **Efficient Deep Learning Models**
- [alselwi2024rnnlstm] *RNN-LSTM: From Applications to Modeling Techniques and Beyond*
  Abstract: Reviews RNN-LSTM variants for time series prediction, focusing on efficiency.
- [waqas2024critical] *A Critical Review of RNN and LSTM Variants in Hydrological Time Series Predictions*
  Abstract: Analyzes the performance of RNN and LSTM models in hydrological applications.
- [liu2024featureefficient] *Feature-Efficient LSTM for Underwater Target Intention Recognition*
  Abstract: Proposes a feature-efficient LSTM for underwater target intention recognition.

## Theme 4: **Efficient Transformers**
- [greff2016lstm] *LSTM: A Search Space Odyssey*
  Abstract: Reviews LSTM variants and their applications.
- [gers2000learning] *Learning to Forget: Continual Prediction with LSTM*
  Abstract: Explores continual learning with LSTMs.

## Theme 5: **Efficient RNNs**
- [jenner2021rnn] *Deep Learning for Efficient Sequence Modeling*
  Abstract: Discusses efficient RNN variants like GRU and LSTM.
- [raffel2019exploring] *Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*
  Abstract: Proposes a unified text-to-text transformer framework for efficient transfer learning.

## Theme 6: **Efficient Neural Networks**
- [wolf2020image] *An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale*
  Abstract: Applies transformers to image recognition, focusing on efficiency.
- [dosovitskiy2020image] *An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale*
  Abstract: Discusses efficient vision transformers using state space models.

## Theme 7: **Efficient Vision Transformers**
- [zhu2024vision] *Vision Mamba: Efficient Vision Transformer using Bidirectional State Space Model*
  Abstract: Integrates Mamba into Vision Transformers for efficient performance.
- [liu2021swin] *Swin Transformer: Hierarchical Vision Transformer using Shifted Windows*
  Abstract: Proposes a hierarchical vision transformer with efficient computation.

## Theme 8: **Efficient Attention Mechanisms**
- [loh2024comparative] *A Comparative Evaluation of Transformers in Seq2Seq Code Mutation*
  Abstract: Compares attention mechanisms in transformers.
- [raffel2019exploring] *Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*
  Abstract: Evaluates attention-based models for transfer learning.
